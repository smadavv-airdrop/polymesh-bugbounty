eve.security CORS Misconfiguration Exploit - HIGH-01

Target: https://platform.eve.security (and platform-prod.eve.security)

Vulnerability: Arbitrary Origin reflection with Access-Control-Allow-Credentials: true

Impact: Authenticated cross-origin requests readable by attacker

Exploit Explanation

When a victim visits this page while logged into eve.security:
1. Browser sends cookies automatically with credentials: 'include'
2. Server reflects Origin header in Access-Control-Allow-Origin
3. Server sets Access-Control-Allow-Credentials: true
4. Attacker JavaScript can READ the response (user data, tokens, etc.)
5. Full account takeover via session hijacking or API abuse
