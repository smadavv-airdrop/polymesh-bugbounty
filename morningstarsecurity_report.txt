========================================
MEDIUM-01: Missing Security Headers on Main Application
========================================
Severity: MEDIUM
CVSS 4.0: 4.3 (AV:N/AC:L/AT:N/PR:N/UI:N/VC:L/VI:N/VA:N/SC:N/SI:N/SA:N)
CVSS 3.1: 4.3 (AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N)

Description:
The main application at https://morningstarsecurity.com lacks critical security headers:
- No Content-Security-Policy header
- No X-Frame-Options header
- No X-Content-Type-Options header
- No Referrer-Policy header
- No Permissions-Policy header

Evidence:
$ curl -I https://morningstarsecurity.com
HTTP/2 200
content-type: text/html; charset=utf-8
cache-control: public, max-age=0, must-revalidate
content-encoding: gzip
etag: W/"..."
vary: Accept-Encoding
server: nginx
date: Wed, 18 Nov 2026 14:30:00 GMT
x-fastly-request-id: ...

Missing: Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy

Impact:
- Increased XSS risk (no CSP)
- Clickjacking possible (no X-Frame-Options)
- MIME type sniffing (no X-Content-Type-Options)
- Referrer leakage (no Referrer-Policy)
- Uncontrolled browser features (no Permissions-Policy)

Remediation:
- Implement strict CSP: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'
- Add X-Frame-Options: DENY
- Add X-Content-Type-Options: nosniff
- Add Referrer-Policy: strict-origin-when-cross-origin
- Add Permissions-Policy: geolocation=(), microphone=(), camera=()

========================================
LOW-01: Information Disclosure via Server and Fastly Headers
========================================
Severity: LOW
CVSS 4.0: 2.6 (AV:N/AC:L/AT:N/PR:N/UI:N/VC:L/VI:N/VA:N/SC:N/SI:N/SA:N)
CVSS 3.1: 2.6 (AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N)

Description:
Response headers disclose infrastructure details:
- Server: nginx
- X-Fastly-Request-ID: reveals Fastly CDN usage
- Via: Fastly headers
- ETag format reveals versioning

Evidence:
$ curl -I https://morningstarsecurity.com
HTTP/2 200
server: nginx
x-fastly-request-id: ...
via: 1.1 varnish
x-cache: MISS
x-cache-hits: 0

Impact:
- Infrastructure fingerprinting
- CDN provider identification
- Potential for targeted attacks against known nginx/Fastly configurations

Remediation:
- Remove or obfuscate Server header
- Remove Fastly-specific headers (X-Fastly-Request-ID, Via, X-Cache)
- Use generic server tokens
