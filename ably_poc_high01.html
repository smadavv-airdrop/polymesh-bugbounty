Exploit Explanation

When a victim visits this page while having valid Ably credentials (API key or token):
1. Browser sends credentials automatically with credentials: 'include'
2. Server reflects Origin header in Access-Control-Allow-Origin
3. Server sets Access-Control-Allow-Credentials: true
4. Attacker JavaScript can READ the response (user data, tokens, keys, messages)
5. Full account takeover: steal API keys, enumerate channels, read all messages,
   register push devices, access presence data, rotate keys

The /time endpoint is particularly dangerous as it's always accessible and
confirms the CORS misconfiguration exists on the authenticated API surface.
